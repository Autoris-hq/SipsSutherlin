# Photos

Drop real photos (video stills, Facebook posts, product shots) into this
folder using these exact filenames — the site picks them up automatically.
Until a file exists, its slot on the page shows a labeled placeholder.

| File | Where it appears | Suggested shot |
| --- | --- | --- |
| `hero.jpg` | Hero, top of page (4:3) | Best lineup of drinks, or the stand with drinks in front |
| `featured-1.jpg` … `featured-6.jpg` | Featured Sips grid (square) | Individual drinks / bowls from the video & Facebook |
| `about.jpg` | About section (4:3) | The drive-thru stand, the window, or the crew |

Tips: JPG around 1200–1600px on the long edge keeps the page fast.
Square crops look best in the featured grid.
